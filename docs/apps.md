# פתיחה בעוזרים שונים

ההוראות נבדקו מול התיעוד הרשמי ב־25 באוקטובר 2026. זמינות סביבת עבודה מקומית יכולה להשתנות לפי היישום והחשבון.

| יישום | איך פותחים |
| --- | --- |
| ChatGPT עם סביבת עבודה מקומית / Codex | מוסיפים את תיקיית הריפו כפרויקט המקומי הראשי ופותחים בה שיחה. הסקילים נמצאים ב־`.agents/skills/`, והוראות השורש ב־`AGENTS.md`. |
| Claude Code בטרמינל או בסביבת הקוד של Desktop | פותחים את תיקיית השורש. `CLAUDE.md` מפנה להוראות המשותפות, והסקילים נמצאים גם ב־`.claude/skills/`. אפשר להפעיל אותם במפורש עם `/davinci-presentation` ו־`/davinci-interactive-video`. |
| Gemini CLI או עוזר אחר עם גישה לתיקייה וכלי קוד | `GEMINI.md` מפנה להוראות המשותפות. אם היישום לא טוען סקילים אוטומטית, בקשו ממנו לקרוא את `AGENTS.md` ואת `SKILL.md` המתאים. |
| צ׳אט רגיל בדפדפן, Cowork או סביבת ענן | אין הנחה של גישה אוטומטית לתיקיית ה־clone או טעינת סקילי פרויקט. יש לחבר תיקייה נתמכת, להשתמש בסביבת קוד מתאימה או להעלות את הקבצים הדרושים. הוראות ומגבלות משתנות לפי המוצר. |

מקורות: [הסקילים המקומיים של Codex](https://learn.chatgpt.com/docs/build-skills), [פרויקטים ותיקיות ב־ChatGPT](https://learn.chatgpt.com/docs/projects), [סקילים ב־Claude Code](https://code.claude.com/docs/en/skills), [הוראות CLAUDE.md](https://code.claude.com/docs/en/memory).

העוזר צריך הרשאה לקרוא ולכתוב בתוך תיקיית הפרויקט ולהריץ Python. ההתקנה הראשונה מורידה ספריות מ־PyPI. יצירת קריינות חדשה שולחת את תמלול הקריינות ל־Google Gemini; בניית המצגת, האנימציה, המוזיקה והנגן נעשית מקומית.

לא צריך להעתיק סקילים לתיקייה האישית או להתקין תוסף כדי להשתמש בפרויקט. אם שיניתם את סקילי המקור, הריצו `python3 scripts/sync_skills.py` כדי לסנכרן את עותקי Claude.
