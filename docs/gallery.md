# ספריית הלמידה

האתר נמצא ב־`projects/learning-library/`. זו אפליקציית Expo Router ל־Web, שמתפרסמת ב־Cloudflare בכתובת [knowledge.davinci4744.com](https://knowledge.davinci4744.com/). היא מציגה מצגות וסרטונים אינטראקטיביים, מאפשרת לחפש גם בשמות הפרקים, לסנן לפי נושא ופורמט ולהוריד PowerPoint. אין צורך בחשבון לצפייה.

הספרייה פתוחה לכולם גם בלי חשבון במערכת למידה. לשילוב בקורס מורידים חבילת SCORM מתוך השיעור ומעלים אותה למערכת הלמידה. ההתקדמות, הציון וההשלמה נשמרים במערכת שמארחת את החבילה. הוראות הייצוא ב־[מדריך SCORM](scorm.md), והוראות הפריסה ב־[מדריך Cloudflare](cloudflare.md).

## הרצה מקומית

נדרשים Python 3.10 ומעלה ו־Node.js 22.13 ומעלה. משורש הריפו:

```sh
python3 scripts/setup.py
cd projects/learning-library
npm ci
npm start
```

אם סביבת Python כבר מותקנת, אפשר לדלג על שלב ההתקנה הראשון. פקודות האתר בוחרות אוטומטית את Python מתוך `.venv`, ובסביבה בלי `.venv` משתמשות ב־Python המותקן. פותחים את כתובת ה־Local שמופיעה במסוף.

```sh
npm run typecheck
npm test
npm run build
```

האתר המוכן מופיע ב־`projects/learning-library/output/site/`. יש להגיש את התיקייה בשרת HTTP; פתיחה ישירה כקובץ אינה תומכת בטעינת הקטלוג. לדוגמה, משורש הריפו:

```sh
.venv/bin/python -m davinci_creator serve projects/learning-library/output/site --port 8000
```

## הוספת תוכן

בכל בנייה נסרקים `examples/*/content.json` ו־`projects/*/content.json`. לכל פרויקט נוצרת מצגת HTML ו־PowerPoint מחדש מתוך התוכן. תוצרי טיוטה ותיקיות ביניים אינם נסרקים. מזהי הפרויקטים חייבים להיות ייחודיים בין שתי התיקיות.

התיאורים, הקטגוריות והבחירה של התוכן המומלץ נמצאים ב־`projects/learning-library/library.json`, לפי שם תיקיית הפרויקט. אפשר גם להגדיר `title` לשם תצוגה קצר בספרייה. פרויקט חדש בלי רשומה מקבל את קטגוריית ״עוד מהקבוצה״ ואת כותרת המשנה שלו כתיאור. לאחר עריכת תוכן בזמן פיתוח, מריצים `npm run prepare:content` ומרעננים את הדף.

כדי לאפשר פתיחה בקישור ישיר בלי להציג תוכן בגלריה, מגדירים `"unlisted": true` ברשומה שלו ב־`library.json`. התוכן נבנה כרגיל ונפתח ב־`?item=<project-id>&view=deck`, אך אינו מופיע בכרטיסים, בחיפוש, בהמלצות, בקטגוריות או במניינים. זו הסתרה מהגלריה: כל מי שמחזיק בקישור יכול לצפות, והקטלוג הציבורי עדיין כולל את הפריט לצורך פתיחתו. אין כאן הגנת סיסמה.

### גלריית הקבוצה

הנתיב `/team-library/` מציג רק פריטים שמסומנים `unlisted: true`: כרגע מצגת הגיוסים ובחירת הצוותים. יש בו אותו חיפוש, סינון, צפייה והורדות PowerPoint ו־SCORM כמו בגלריה הציבורית. פתיחת פריט, החלפת פורמט וחזרה לספרייה נשארות בנתיב הקבוצה, למשל `/team-library/?item=recruitment&view=deck`. הקישורים הישירים הקיימים משורש האתר ממשיכים לעבוד.

אין קישור לגלריית הקבוצה מתוך הגלריה הציבורית. הדף כולל `noindex,nofollow`, ומפת האתר האוטומטית של Expo מבוטלת כדי שלא תציג קישור לנתיב. שתי הגלריות משתמשות באותו קטלוג ציבורי; הנתיב אינו דורש התחברות ומקורות התכנים נשארים במאגר הנוכחי. ההפרדה היא לתצוגה ולניווט.

מצגת בחירת הצוותים זמינה בקישור `https://knowledge.davinci4744.com/?item=team-selection&view=deck` ומוגדרת `unlisted: true`, כך שאינה מופיעה בגלריה הציבורית.

מצגת הגיוסים זמינה ב־`https://knowledge.davinci4744.com/?item=recruitment&view=deck`. היא נבנית מ־JSON עם טקסט חי, גופני Rubik ואנימציות כניסה כמו שאר המצגות. הסרטונים ממלאים את כל השקף ונפתחים במסך מלא בלחיצה. סמלי הצוותים שקופים; בשקף 3 אין קישור כפול לסרטון שבשקף 4. ה־PowerPoint המעוצב מחדש ניתן לעריכה; קובץ המקור נשמר בנפרד ב־`projects/recruitment/source/`. סרטוני YouTube דורשים אינטרנט. פרטי העריכה נמצאים בבריף הפרויקט.

המצגות נבנות ללא קריינות וללא מפתחות API. וידאו מופיע רק כשיש חבילת נגן שנשמרה לפרסום, או כשקיים נגן מוכן בתוך דוגמה ב־`examples/`.

## הוספת סרטון לפרסום

תוצרי הווידאו הרגילים תחת `output/video/` מוחרגים מ־Git. כדי שסרטון יהיה זמין גם בבנייה ב־GitHub, שומרים במכוון עותק של חבילת הנגן לפרסום. למשל, משורש הריפו:

```sh
.venv/bin/python scripts/prepare_gallery.py \
  --publish-video frc-electrical-basics \
  --from projects/frc-electrical-basics/output/video/interactive
```

הפקודה מעתיקה את הווידאו ואת המשאבים שהנגן מפנה אליהם אל `projects/learning-library/output/published/<id>/interactive/`. התיקייה הזו מוחרגת במכוון מכלל ההתעלמות מתוצרים: מוסיפים אותה ל־Git יחד עם קובץ התוכן של הפרויקט. בבנייה הבאה הסרטון יופיע אוטומטית. החלפת הווידאו המקורי לא מעדכנת את העותק שפורסם; מריצים שוב את הפקודה לאחר אישור הגרסה החדשה.

נשמרים רק משאבים שהנגן מפנה אליהם, עם סיומות מאושרות. קובצי קריינות, מטמון ותיקיות בנייה אינם מועתקים. קישור יחסי לווידאו שנמצא מחוץ לתיקיית הנגן הופך לקובץ `video.mp4` בתוך החבילה. גופני Rubik ורישיונם נכללים באתר. להסרת סרטון מהקטלוג, מסירים את תיקיית הפרסום שלו ובונים מחדש. הסרטונים המוכנים שבדוגמאות נשארים זמינים כל עוד הם קיימים בדוגמה.

## פריסה דרך GitHub Actions ל־Cloudflare

התהליך ב־`.github/workflows/cloudflare.yml` בודק את הקוד, יוצר את המצגות, בודק את חבילות SCORM ואת שירות הווידאו ומפרסם את התוצר ל־Cloudflare. הוא רץ על דחיפה ל־`master` או `main`, ואפשר להפעיל אותו ידנית. פרסום מתבצע רק מהענף הראשי של הריפו ולא מתוך Pull requests. העבודה עם קוד המקור נשארת ב־GitHub; אין פריסה ל־GitHub Pages.

1. מעלים לריפו את קוד האתר, ה־lockfile, קובצי התוכן וחבילות הווידאו שנבחרו לפרסום.
2. מוסיפים את סוד הפריסה `CLOUDFLARE_API_TOKEN` ל־**Settings → Secrets and variables → Actions**, לפי [מדריך Cloudflare](cloudflare.md).
3. מפעילים את **Learning library** או דוחפים שינוי לענף הראשי.

האתר נבנה בשורש הדומיין, עם `EXPO_BASE_URL` ריק. קישור ציבורי לתוכן נראה כך: `?item=community&view=video`. הפריסה אינה דורשת הגדרות מערכת למידה, מסד נתונים או מפתחות חתימה. נתיבי האינטגרציה הישנים תחת `/lti/` מחזירים HTTP 410.

לבדיקת חבילת הפריסה, משורש הריפו:

```sh
npm --prefix projects/learning-library/cloudflare run check:deploy
```

הכתובת הישנה `learn.davinci4744.com` משמשת להפניית קישורים ציבוריים בלבד אל `knowledge.davinci4744.com`. נתיבי האינטגרציה הישנים מחזירים HTTP 410 בשתי הכתובות. ההתקדמות והתוצאות של חבילות SCORM נשמרות במערכת הלמידה שמארחת אותן. קובצי MP4 נשמרים בריפו כחלק מחבילת פרסום; קובץ מעל 25 MiB דורש אחסון מדיה חלופי לפני פריסה. האתר אינו משתמש ב־Git LFS.

## גלריית לימודים והכנה למבחנים

הנתיב `/study-library/` מיועד לחומרי לימוד ותרגול למקצועות בית הספר, מחוץ לרובוטיקה. אין אליו קישור מהגלריה הציבורית או מגלריית הקבוצה. הדף כולל `noindex,nofollow`, ומפת האתר נשארת מבוטלת. הגישה היא בקישור ישיר בלבד; זו הפרדת תצוגה וניווט, ללא דרישת התחברות.

הגלריה מציגה רק תכני לימודים שסומנו עבורה. לפני הוספת תוכן היא מציגה „התוכן הראשון בדרך”. החיפוש, סינון המקצועות והפורמטים, התוכן המומלץ וההורדות פועלים באותה תשתית של שאר הספריות.

התוכן הראשון הוא `physics-forces-exam`, בקטגוריית „פיזיקה”: חזרה מונפשת של כ־11 דקות על כוחות ומצבי התמד, עם קריינות Gemini, שני ניסויי הדגמה, שלושה תרגילים מתקדמים ושבע שאלות הבנה. הגרסה המורחבת כוללת טריגונומטריה וזהויות, פירוט משתנים ויחידות בהופעה ראשונה, ומילון סימונים בנגן. חיכוך קינטי אינו נכלל. פרטי הכיסוי והמקורות נמצאים בתיקיית הפרויקט. המספרים בניסויים הם להמחשה, ולא מדידות הכיתה. הגלריה זמינה בקישור ישיר ב־`https://knowledge.davinci4744.com/study-library/`, ללא קישור מהעמודים הקיימים.

כדי להוסיף את התוכן הראשון, יוצרים פרויקט רגיל עם `content.json`, ומוסיפים ב־`library.json` רשומה לפי מזהה הפרויקט עם `"gallery": "study"`, קטגוריה לפי מקצוע ותיאור. לדוגמה, עבור פרויקט עתידי בשם `math-review`:

```json
{
  "math-review": {
    "gallery": "study",
    "title": "חזרה למבחן במתמטיקה",
    "category": "מתמטיקה",
    "description": "הסברים ותרגול לקראת המבחן.",
    "featured": true
  }
}
```

`gallery` קובע באיזו גלריה מופיע הפריט. בלי השדה נשמרת ההתנהגות הקיימת: `unlisted: true` משייך לגלריית הקבוצה, ושאר הפריטים לגלריה הציבורית. תכני `study` אינם מופיעים בחיפוש, בהמלצות או במניינים של הגלריות האחרות. צפייה והחלפת פורמט נשארות בנתיב הלימודים, למשל `/study-library/?item=math-review&view=deck`, וכפתור החזרה מחזיר לגלריית הלימודים.

## מבנה הקוד

בכל שיעור, הכפתור „ייצוא” פותח דיאלוג שמאפשר לבחור מצגת או סרטון ולהוריד ZIP של SCORM. החבילות נבנות עם האתר ונכללות בקטלוג תחת `scorm`. גרסת הווידאו ב־ZIP מותאמת לקורס: נגן ישיר, כותרת אחת ושאלון סיום אחד. אין צורך בחיבור למערכת למידה בזמן הבנייה; מדריך ההפעלה נמצא ב־[SCORM](scorm.md).

- `app/`: נקודות הכניסה לגלריה הציבורית, לגלריית הקבוצה ולגלריית הלימודים, הגדרת HTML וערכת הנושא.
- `src/routes/`: חיבור הפרמטרים בכתובת לפעולות המסך, עם שמירת הקשר הגלריה בניווט.
- `src/screens/`: הרכבת מסך הספרייה והצפייה.
- `src/features/catalog/`: מצב חיפוש וסינון ב־MobX וכרטיסי התוכן.
- `src/core/`: טעינת הקטלוג דרך חוזה repository מוזרק.
- `src/models/`: מבנה פריט תוכן וחוזי הנתונים.
- `src/ui/`: ערכת נושא, רכיבים בסיסיים וגבול הדפדפן לנגן וקישורי הורדה.
- `scripts/prepare_gallery.py`: יצירת המצגות, אריזת המדיה והקטלוג.

מצב נגזר מחושב ב־getters. המסך מקבל callbacks לפעולות פתיחה וחזרה; הניתוב מרוכז ב־`src/routes/` ונקודות הכניסה ב־`app/`. ה־store נוצר בגבול הדף, מבטל בקשות ביציאה ומתעלם מתוצאות מאוחרות. רכיבי הממשק משתמשים ב־React Native Web וב־styled-components/native; שילוב HTML לנגן, לקישורים ולאייקונים מרוכז ברכיבי הדפדפן. הבדיקות מכסות חיפוש משולב, סינון, כשל וטעינה חוזרת, ניקוי lifecycle ואריזת נגן עם קישורי מדיה יחסיים.

מקורות להגדרות הפריסה: [Expo — פרסום אתרים](https://docs.expo.dev/guides/publishing-websites/) ו־[Cloudflare — GitHub Actions](https://developers.cloudflare.com/workers/ci-cd/external-cicd/github-actions/).
