# ספריית הלמידה

האתר נמצא ב־`projects/learning-library/`. זו אפליקציית Expo Router ל־Web עם ייצוא סטטי ל־GitHub Pages. היא מציגה מצגות וסרטונים אינטראקטיביים, מאפשרת לחפש גם בשמות הפרקים, לסנן לפי נושא ופורמט ולהוריד PowerPoint. אין צורך בחשבון או בשירות חיצוני לצפייה.

הספרייה פתוחה לכולם גם בלי חשבון במערכת למידה. אפשר גם לחבר אותה למערכת למידה באמצעות LTI 1.3, לבחור שיעורים מתוך הקורס ולדווח על ציונים והשלמה. החיבור משתמש בשירות Python נפרד ובאירוח HTTPS. הוראות ההגדרה והבדיקה נמצאות ב־[מדריך LTI](lti.md).

## הרצה מקומית

נדרשים Python 3.10 ומעלה ו־Node.js 22.13 ומעלה. משורש הריפו:

```sh
python3 scripts/setup.py
cd projects/learning-library
npm ci
npm start
```

אם סביבת Python כבר מותקנת, אפשר לדלג על שלב ההתקנה הראשון. פקודות האתר בוחרות אוטומטית את Python מתוך `.venv`, ובסביבה בלי `.venv` משתמשות ב־Python המותקן. פותחים את כתובת ה־Local שמופיעה במסוף.

```sh
npm run typecheck
npm test
npm run build
```

האתר המוכן מופיע ב־`projects/learning-library/output/site/`. יש להגיש את התיקייה בשרת HTTP; פתיחה ישירה כקובץ אינה תומכת בטעינת הקטלוג. לדוגמה, משורש הריפו:

```sh
.venv/bin/python -m davinci_creator serve projects/learning-library/output/site --port 8000
```

## הוספת תוכן

בכל בנייה נסרקים `examples/*/content.json` ו־`projects/*/content.json`. לכל פרויקט נוצרת מצגת HTML ו־PowerPoint מחדש מתוך התוכן. תוצרי טיוטה ותיקיות ביניים אינם נסרקים. מזהי הפרויקטים חייבים להיות ייחודיים בין שתי התיקיות.

התיאורים, הקטגוריות והבחירה של התוכן המומלץ נמצאים ב־`projects/learning-library/library.json`, לפי שם תיקיית הפרויקט. אפשר גם להגדיר `title` לשם תצוגה קצר בספרייה. פרויקט חדש בלי רשומה מקבל את קטגוריית ״עוד מהקבוצה״ ואת כותרת המשנה שלו כתיאור. לאחר עריכת תוכן בזמן פיתוח, מריצים `npm run prepare:content` ומרעננים את הדף.

המצגות נבנות ללא קריינות וללא מפתחות API. וידאו מופיע רק כשיש חבילת נגן שנשמרה לפרסום, או כשקיים נגן מוכן בתוך דוגמה ב־`examples/`.

## הוספת סרטון לפרסום

תוצרי הווידאו הרגילים תחת `output/video/` מוחרגים מ־Git. כדי שסרטון יהיה זמין גם בבנייה ב־GitHub, שומרים במכוון עותק של חבילת הנגן לפרסום. למשל, משורש הריפו:

```sh
.venv/bin/python scripts/prepare_gallery.py \
  --publish-video frc-electrical-basics \
  --from projects/frc-electrical-basics/output/video/interactive
```

הפקודה מעתיקה את הווידאו ואת המשאבים שהנגן מפנה אליהם אל `projects/learning-library/output/published/<id>/interactive/`. התיקייה הזו מוחרגת במכוון מכלל ההתעלמות מתוצרים: מוסיפים אותה ל־Git יחד עם קובץ התוכן של הפרויקט. בבנייה הבאה הסרטון יופיע אוטומטית. החלפת הווידאו המקורי לא מעדכנת את העותק שפורסם; מריצים שוב את הפקודה לאחר אישור הגרסה החדשה.

נשמרים רק משאבים שהנגן מפנה אליהם, עם סיומות מאושרות. קובצי קריינות, מטמון ותיקיות בנייה אינם מועתקים. קישור יחסי לווידאו שנמצא מחוץ לתיקיית הנגן הופך לקובץ `video.mp4` בתוך החבילה. גופני Rubik ורישיונם נכללים באתר. להסרת סרטון מהקטלוג, מסירים את תיקיית הפרסום שלו ובונים מחדש. הסרטונים המוכנים שבדוגמאות נשארים זמינים כל עוד הם קיימים בדוגמה.

## GitHub Pages

התהליך ב־`.github/workflows/pages.yml` בודק את הקוד, יוצר את המצגות, מייצא את האתר ומעלה תוצר פריסה. הוא רץ על דחיפה ל־`master` או `main`, ואפשר להפעיל אותו ידנית. Pull requests נבדקים ונבנים בלי לפרסם.

1. מעלים לריפו את קוד האתר, ה־lockfile, קובצי התוכן וחבילות הווידאו שנבחרו לפרסום.
2. בהגדרות הריפו פותחים **Settings → Pages → Source** ובוחרים **GitHub Actions**.
3. מפעילים את **Learning library** או דוחפים שינוי לענף הראשי.

הפריסה לוקחת את נתיב הבסיס מהגדרות Pages, ולכן תומכת גם בכתובת של ריפו, גם באתר ארגוני וגם בדומיין מותאם. קובץ `.nojekyll` שומר על קובצי Expo שמתחילים בקו תחתון. קישור לתוכן נראה כך: `?item=community&view=video`, ולכן טעינה מחדש וקישורים משותפים אינם דורשים כללי שכתוב בשרת.

לבדיקת בנייה עם נתיב של ריפו, מתוך תיקיית האתר:

```sh
EXPO_BASE_URL=/content-creator npm run build
```

יש להגיש את התוצר באותו נתיב, `/content-creator/`. קובצי MP4 נשמרים בריפו כחלק מחבילת פרסום; סרטונים גדולים צריכים להתאים למגבלות הגודל והנפח של GitHub ו־Pages. האתר אינו משתמש ב־Git LFS.

## מבנה הקוד

- `app/`: הגדרת הדף, ערכת הנושא וחיבור הפרמטרים בכתובת לפעולות מסך.
- `src/screens/`: הרכבת מסך הספרייה והצפייה.
- `src/features/catalog/`: מצב חיפוש וסינון ב־MobX וכרטיסי התוכן.
- `src/core/`: טעינת הקטלוג דרך חוזה repository מוזרק.
- `src/models/`: מבנה פריט תוכן וחוזי הנתונים.
- `src/ui/`: ערכת נושא, רכיבים בסיסיים וגבול הדפדפן לנגן וקישורי הורדה.
- `scripts/prepare_gallery.py`: יצירת המצגות, אריזת המדיה והקטלוג.

מצב נגזר מחושב ב־getters. המסך מקבל callbacks לפעולות פתיחה וחזרה; הניתוב נשאר ב־`app/`. ה־store נוצר בגבול הדף, מבטל בקשות ביציאה ומתעלם מתוצאות מאוחרות. רכיבי הממשק משתמשים ב־React Native Web וב־styled-components/native; שילוב HTML לנגן, לקישורים ולאייקונים מרוכז ברכיבי הדפדפן. הבדיקות מכסות חיפוש משולב, סינון, כשל וטעינה חוזרת, ניקוי lifecycle ואריזת נגן עם קישורי מדיה יחסיים.

מקורות להגדרות הפריסה: [Expo — פרסום אתרים](https://docs.expo.dev/guides/publishing-websites/) ו־[GitHub — תהליך פריסה מותאם ל־Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).
