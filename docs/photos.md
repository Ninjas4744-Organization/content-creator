# תמונות מאלבומי הקבוצה

אפשר לקטלג ולייבא תמונות מאלבומי Google Photos שפתוחים לצפייה באמצעות קישור משותף. אין צורך בחשבון, במפתח API או בתוסף לדפדפן. אלבום שדורש התחברות אינו נתמך.

המקורות שמורים ב־`assets/photo-albums.json`:

| מזהה | אלבום |
| --- | --- |
| `isr-district-2-2026` | [Ninjas 4744 - 2026 ISR District #2](https://photos.app.goo.gl/Zs53pe3BLspx6Xk46) |
| `israel-championship-2026` | [Ninjas 4744 - 2026 Israel District Championship](https://photos.app.goo.gl/tCNAkg8fPMZCYf759) |
| `season-2026` | [עונה 2026](https://photos.app.goo.gl/wFGoG4N5dJk2WuGK8) |

## שימוש

הריצו משורש הריפו לאחר ההתקנה הרגילה. ב־Windows החליפו `.venv/bin/python` ב־`.venv\Scripts\python.exe`.

```sh
# רשימת המקורות ללא חיבור לרשת
.venv/bin/python -m davinci_creator photos albums

# קטלוג מלא, כולל עמודים נוספים באלבומים גדולים
.venv/bin/python -m davinci_creator photos catalog season-2026

# ייבוא 12 התמונות הראשונות, עד 2400 פיקסלים בצלע הארוכה
.venv/bin/python -m davinci_creator photos import season-2026

# טווח אחר באלבום; offset מתחיל באפס
.venv/bin/python -m davinci_creator photos import season-2026 --offset 40 --limit 8 --size 3200

# ייבוא תמונה מסוימת לפי המזהה שמופיע בקטלוג; אפשר לחזור על --photo-id
.venv/bin/python -m davinci_creator photos import season-2026 --photo-id PHOTO_ID_FROM_CATALOG

# קישור חדש, גם בלי להוסיף אותו לרשימת המקורות
.venv/bin/python -m davinci_creator photos import "https://photos.app.goo.gl/Zs53pe3BLspx6Xk46" --limit 4
```

`catalog` יוצר `outputs/photo-albums/<id>/index.html` ו־`catalog.json`. פתחו את ה־HTML כדי לבחור תמונות לפי המראה שלהן; ליד כל תמונה מופיע המזהה ל־`--photo-id`. התמונות הממוזערות בקטלוג נטענות מ־Google ודורשות אינטרנט. כתובותיהן עשויות לפוג; הריצו שוב את הקטלוג כדי לרענן אותן. כדי לשמור קטלוג בנפרד מתצוגת הייבוא, הוסיפו `--out outputs/photo-albums/season-2026/catalog`.

`import` שומר JPEG מקומיים ב־`assets/photos/albums/<id>/`, עם `manifest.json` שמתעד קישור מקור, מזהה תמונה, מידות ו־SHA-256. פרטי תורמי האלבום אינם נשמרים, ונתוני EXIF/GPS מוסרים מהתמונות המיובאות. זו עותק מוקטן ליצירת תוכן; המקור ב־Google אינו משתנה. סרטונים מדולגים ואינם מיובאים כתמונות.

תצוגת הייבוא נשמרת ב־`outputs/photo-albums/<id>/`: דף HTML עם תמונות ממוזערות מוטמעות ונתיבי התמונות להעתקה, `manifest.json` עבור הבחירה הנוכחית ו־`storyboard.jpg` לבדיקה חזותית של עד 48 התמונות הראשונות. דף התצוגה נפתח עצמאית ללא אינטרנט; קובצי התמונה לשימוש בתוכן נשארים ב־`assets/`. `--out` משנה רק את תיקיית התצוגה. ייבוא חוזר משתמש בקבצים שכבר הורדו ונבדקו; עדיין נדרש חיבור לקריאת מצב האלבום. כל תמונה נשמרת במניפסט מיד לאחר הורדתה, כך שאפשר להריץ שוב לאחר ניתוק. קובץ ששונה מקומית אינו נדרס. `--limit 0` בוחר במפורש את כל התמונות, ו־`--photo-id` בוחר את המזהים שביקשתם במקום טווח ה־offset/limit.

## שילוב במצגת או בסרטון

העתיקו את שדה `image` מתוך מניפסט הייבוא אל סצנת `photo` או פריט עם תמונה ב־`content.json`, למשל:

```json
{
  "id": "team-at-work",
  "layout": "photo",
  "title": "הקבוצה בפעולה",
  "image": "photos/albums/season-2026/FILE_NAME_FROM_MANIFEST.jpg",
  "body": "הסבר שמתאים לתמונה שבחרתם"
}
```

הנתיב יחסי ל־`assets/`, כמו יתר התמונות בריפו. כלי המצגות והסרטונים הקיימים משתמשים בקובץ המקומי; ייצוא המצגת והווידאו אינו תלוי בקישור ל־Google. בדקו את ה־storyboard לפני בחירה סופית. שמות האלבומים אינם הוכחה להישגים, תפקידים או זהויות של המצולמים.

הורדות האלבומים ותוצרי התצוגה מוחרגים מ־Git כדי לא להוסיף אוטומטית מאות תמונות. רשימת האלבומים והכלי עצמו נשמרים בריפו. תמונות שנבחרו לשיעור נשמרות עם חבילת המקורות ב־R2: הפניות בקובץ התוכן נאספות אוטומטית, ותלויות דינמיות נרשמות ב־`publication.json` תחת `source_assets`. שמרו גם את רשומות המקור בפרויקט. ראו [שחזור ושמירת מקורות](project-sources.md). שמרו את התמונות לשימוש המורשה של הקבוצה; קישור משותף אינו רישיון הפצה כללי.

## מגבלות ובדיקה

הייבוא קורא את המידע המוטמע בדף האלבום המשותף ואת בקשת העימוד שלו. זהו מבנה לא מתועד של Google שעשוי להשתנות. הכלי אינו מריץ סקריפטים מהעמוד ואינו קורא עוגיות או פרטי התחברות. עמודים חוזרים או עמודים שלא ניתן לפענח גורמים לשגיאה. פער בין ספירת Google לבין הפריטים שהתקבלו אחרי סיום כל העמודים מדווח בשורת הפקודה, במניפסט ובדף הבחירה; אין הנחה שהפריטים החסרים ניתנים להורדה. לדוגמה, בבדיקת האלבום העונתי ב־28.10.2026 Google דיווחה על 1,517 פריטים והחזירה 1,516 פריטי מדיה, לפני סינון הסרטונים. אם Google משנה את המבנה או מבטלת את השיתוף, אפשר להוריד תמונות ידנית ולשמור אותן ב־`assets/`.

ה־Library API הרשמי אינו מספק גישה כללית לאלבומי שיתוף קיימים מאז השינויים ב־2025; לכן היכולת הזו אינה משתמשת בו. ראו [התיעוד הרשמי של Google](https://developers.google.com/photos/support/updates).

```sh
.venv/bin/python -m unittest discover -s tests -p test_photos.py -v
```
