מ־clone ל־Pull Request

משכפלים את הריפו, פותחים בכלי ה־AI שנוח לכם, וממשיכים בעזרת בקשות ברורות. אפשר להעתיק את הניסוחים ולשנות את הנושא, הקהל והמשך.

פתיחת הריפו ב־GitHub · הורדת כל הבקשות

Clone

git clone https://github.com/Ninjas4744-Organization/content-creator.git
cd content-creator

פותחים את תיקיית השורש של הריפו בעוזר שמסוגל לקרוא ולערוך קבצים ולהריץ את כלי הפרויקט. הסקילים נשמרים בפרויקט תחת .agents/skills/. אם אינם מזוהים אוטומטית, אפשר לבקש מהעוזר לקרוא את קובץ SKILL.md המתאים.

פתיחת פרויקט

קרא את AGENTS.md ואת הוראות הפרויקט. ודא שיש לך גישה לתיקיית הריפו. אם צריך, הכן את סביבת העבודה לפי התיעוד. פתח ענף עבודה חדש בשם codex/my-lesson.

יצירת סרטון

השתמש בסקיל davinci-interactive-video. צור פרויקט חדש לסרטון בעברית באורך שתי דקות למדריכים חדשים על בדיקת הבנה. המטרה: לדעת לנסח שאלה עם משוב מועיל. הוסף דוגמה ושאלת תרגול. הצג תסריט ותצוגה מקדימה.

יצירת מצגת

השתמש בסקיל davinci-presentation. צור מצגת בעברית למדריכים חדשים על בדיקת הבנה. המטרה: לדעת לנסח שאלה עם משוב מועיל. שמור על מיתוג Da Vinci 4744 והפק תוצרים ניתנים לבדיקה.

משוב ממוקד

בסצנה השלישית צריך להראות דוגמה מעשית. קצר את ההקדמה, והוסף שאלה שמוודאת שהבינו. עדכן את מקור התוכן ואת התוצרים, והצג שוב את התצוגה המקדימה.

הפקה ובדיקה

הפק את הסרטון המלא והנגן האינטראקטיבי. הרץ את הבדיקות המתאימות, והצג לי קישורים לווידאו, לנגן ולמקור התוכן. ציין מה דורש צפייה או האזנה שלי. אם חסרה הגדרת קריינות, בקש משתנה סביבה או נתיב פרטי; אין לכתוב מפתח בצ׳אט או בריפו.

הכנה לאתר

הכן את השיעור להוספה לספריית הלמידה: רשומת קטלוג עם תיאור וקטגוריה, חבילת פרסום מלאה לווידאו, וכל הנכסים הנדרשים. בנה את האתר מקומית ובדוק שהשיעור נפתח בפורמטים שיצרנו.

Commit

הצג אילו קבצים השתנו. הכן commit בענף העבודה של השיעור עם התוכן, הנכסים וחבילת הפרסום הנדרשת. שמור שינויים שאינם שייכים לשיעור מחוץ ל־commit. אל תכלול מפתחות, קבצים פרטיים או תוצרי ביניים.

Push ו־Pull Request

דחוף את ענף העבודה ל־GitHub ופתח Pull Request. כתוב מה נוצר, למי הוא מיועד ואיך נבדק. צרף תצוגה מקדימה או קישור לתוצר אם אפשר, ושלח לי את הקישור ל־PR. אל תמזג אותו כחלק מהבקשה.

תיקון אחרי סקירה

קרא את ההערות ב־Pull Request, תקן את התוכן והתוצרים באותו ענף, הרץ בדיקות מתאימות, צור commit נוסף ודחוף אותו כדי לעדכן את אותה בקשת מיזוג.

אחרי הסקירה

לאחר אישור ובדיקות מוצלחות, ממזגים לפי נוהל הקבוצה. תהליך האתר בונה ופורס את השינוי מהענף הראשי. בודקים שהשיעור מופיע ושהתוצרים נפתחים באתר הציבורי.

אם אין הרשאת דחיפה לריפו, בקשו מהעוזר להציע את מסלול ההרשאה או ה־fork המתאים. התהליך המדויק תלוי בהרשאות ובנוהל הקבוצה.
