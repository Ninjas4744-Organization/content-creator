# יוצרים תוכן עם ה־AI שלכם

קהל: חברי קבוצה ומנטורים שרוצים ליצור תוכן בעזרת העוזר שבחרו.
מטרה: clone לריפו → פתיחה בעוזר עם גישה לקבצים → בקשת סקיל ותוכן → משוב ובדיקה → commit בענף → push ו־Pull Request → סקירה, מיזוג ופרסום.
ההדרכה מציגה בקשות מוכנות לעוזר ותהליך עבודה, בלי ללמד את מנגנון הרינדור או שדות קובץ התוכן.
משך משוער: 4–5 דקות לפי הקריינות בפועל.
תיקון המשתמש: להתמקד בשכפול הריפו, עבודה עם AI, הפעלת הסקיל וזרימת branch/commit/PR.
תוצר: MP4 ונגן אינטראקטיבי עם שתי שאלות; דף עזר עם קישור לריפו ובקשות להעתקה.
לא מתבצעת פתיחת PR או פריסה חיה כחלק מהפקת ההדרכה.
