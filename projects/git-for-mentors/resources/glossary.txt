Git — גיט
כלי לניהול היסטוריית גרסאות של קבצים.

GitHub — גיטהאב
שירות ברשת לשיתוף מאגרים, דיון וסקירת שינויים.

Repository / Repo — ריפו / מאגר
קובצי הפרויקט והיסטוריית הגרסאות שלהם.

Clone — קלון / שכפול
יצירת עותק מקומי של המאגר מהמקור המרוחק.

Branch — בראנץ׳ / ענף
מסלול התקדמות של שינויים בתוך הפרויקט.

Main branch — הענף הראשי
הענף שהקבוצה משתמשת בו כגרסה המשותפת; לעיתים נקרא main או master.

Commit — קומיט
תיעוד מצב נבחר של הקבצים בהיסטוריה, עם תיאור קצר.

Push — פּוּשׁ
שליחת קומיטים ופרטי ענף למאגר מרוחק, כמו זה שב־GitHub.

Pull — פּוּל
קבלת שינויים מהמאגר המרוחק ושילובם בענף המקומי.

Pull Request / PR — פול ריקווסט / פי אר
בקשה לסקור שינויים בענף ולשלב אותם בענף יעד.

Review — סקירה
בדיקה ומשוב של חברי הצוות על השינויים.

Merge — מֶרְג׳ / מיזוג
שילוב התקדמות ושינויים בין ענפים.
