גיט וגיטהאב — מילון למנטורים

בסיפור הדמיוני שלנו, לאונרדו דה וינצ׳י יוצר שיעור לספריית הקבוצה. המילים מתארות איפה עובדים, מתי שומרים ואיך משתפים לבדיקה.

בקשה שאפשר להעתיק לעוזר

אני חדש/ה בעבודה עם Git ו־GitHub. עזור לי ליצור שיעור בענף עבודה נפרד, לתעד את השינויים ב־commit, לשלוח אותם ב־push ולפתוח Pull Request לסקירה. הסבר בשפה פשוטה לפני כל שלב. בדוק את מצב הפרויקט ושמור על שינויים אחרים.

שלושה דברים לזכור

  • Commit שנוצר במחשב מתעד גרסה מקומית; Push משתף אותה עם המאגר המרוחק.
  • Pull מקבל ומשלב עדכונים. Pull Request הוא בקשה לסקירה ושילוב בין ענפים.
  • בספרייה שלנו, פרסום באתר מגיע אחרי המיזוג לענף הראשי והצלחת הבנייה והפריסה.
