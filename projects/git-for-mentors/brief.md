# גיט וגיטהאב למנטורים

קהל: מנטורים ויוצרי תוכן ללא רקע בתכנות.
מטרה: להבין את אוצר המילים במדריך היצירה עם AI דרך סיפור של הוספת שיעור.
משך: כשלוש דקות, לפי הקריינות בפועל.
מושגים: Git, GitHub, repo, clone, branch, הענף הראשי, commit, push, pull, Pull Request ו־merge.
דוגמה עקבית: סיפור דמיוני שבו לאונרדו דה וינצ׳י מוסיף שיעור לספריית הקבוצה.
אין פקודות טרמינל או התקנות בסרטון; זהו פרק גישור לפני מדריך היצירה.
תוצר: MP4, נגן אינטראקטיבי עם שתי שאלות, כתוביות ומילון מושגים להדפסה מהדפדפן.
מיתוג: Da Vinci 4744, Rubik, עברית RTL וקולות Kore ו־Puck לסירוגין.

עדכון: כותרות הסצנות בעברית בלבד. המונחים באנגלית מוצגים בשורות נפרדות כדי לשמור על סדר קריאה ברור.
