# ערכת יצירה · דה וינצ׳י 4744

1. חלצו את ה־ZIP לתיקייה קבועה במחשב.
2. פתחו את התיקייה בסוכן AI שיכול לקרוא קבצים ולהריץ פקודות. הסקילים נמצאים ב־`.agents/skills` וב־`.claude/skills`; אם הסוכן דורש טעינה או התקנה של סקילים, בצעו אותה פעם אחת מתוך התיקייה.
3. ליצירת מצגת, בקשו: `$davinci-presentation צור מצגת בנושא [הנושא שלי] לקהל [קהל היעד].`
4. ליצירת סרטון, בקשו: `$davinci-interactive-video צור סרטון אינטראקטיבי בנושא [הנושא שלי] לקהל [קהל היעד].`
5. אחרי שבדקתם את התוצר, בקשו: `$davinci-publish פרסם את התוכן בספריית [שם הספרייה] באתר.` התחברו בדפדפן עם החשבון המורשה שלכם לאדמין כאשר הסוכן מבקש זאת.
6. לעדכון, בקשו: `$davinci-update עדכן את הסקילים וכלי היצירה.`

מפעילים את הסקיל המתאים ישירות בשם שלו; אין צורך לבקש לקרוא את `AGENTS.md` בכל בקשה. סקילי היצירה מדריכים את הסוכן להכין את סביבת העבודה לפי הצורך.

הערכה כוללת שני סקילי יצירה, סקיל פרסום וסקיל עדכון, את כלי היצירה, המיתוג והגופנים. אין צורך בגישה ל־Git או במפתחות Cloudflare. נדרשים Python 3.10 ומעלה, חיבור לאינטרנט והרשאה להתקנת כלי היצירה; הסוכן יכין סביבה מקומית. החיבור לאתר משתמש ב־cloudflared ובהתחברות האישית שלכם. שירותי AI והפקת קריינות משתמשים בחשבון ובאישורים שלכם בנפרד.

מקורות התוכן נשארים ב־`projects/`, ותוצרים ב־`outputs/` או בתיקיית `output/` של הפרויקט. פרסום שומר גם גיבוי פרטי של המקורות. אפשר להוריד גם מקורות ישנים שנשמרו באתר. אם מישהו פרסם בינתיים גרסה חדשה, הסוכן יעצור ויבקש לשלב אותה עם העריכות המקומיות. קבצים שפורסמו מיועדים לצפייה באתר; בחירת ספרייה אינה הרשאת צפייה פרטית.
