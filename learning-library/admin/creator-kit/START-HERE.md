# ערכת יצירה · דה וינצ׳י 4744

1. חלצו את ה־ZIP לתיקייה קבועה במחשב.
2. פתחו את התיקייה בסוכן AI שיכול לקרוא קבצים ולהריץ פקודות. הסקילים נמצאים ב־`.agents/skills` וב־`.claude/skills`; אם הסוכן דורש טעינה או התקנה של סקילים, בצעו אותה פעם אחת מתוך התיקייה.
3. ליצירת מצגת, בקשו: `$davinci-presentation צור מצגת בנושא [הנושא שלי] לקהל [קהל היעד].`
4. ליצירת סרטון, בקשו: `$davinci-interactive-video צור סרטון אינטראקטיבי בנושא [הנושא שלי] לקהל [קהל היעד].`
5. לייבוא תוכן קיים, בקשו `$davinci-import ייבא את [קובץ המקור או שם הפריט בספרייה] לפרויקט מקומי.`
6. אחרי שבדקתם את התוצר, בקשו: `$davinci-publish פרסם את התוכן בספריית [שם הספרייה] באתר.` התחברו בדפדפן עם החשבון המורשה שלכם לאדמין כאשר הסוכן מבקש זאת.
7. לעדכון, בקשו: `$davinci-update עדכן את הסקילים וכלי היצירה.`

מפעילים את הסקיל המתאים ישירות בשם שלו; אין צורך לבקש לקרוא את `AGENTS.md` בכל בקשה. הסקילים מדריכים את הסוכן לבדוק את סביבת העבודה, להתקין Python ותלויות חסרות לפי מערכת ההפעלה, ולאמת שהכלים תקינים לפני המשך העבודה. אין צורך להתקין אותם מראש; ראו `docs/setup.md`.

באזור **מקורות** באדמין אפשר להוסיף אלבומי Google Photos ולתאר באילו נושאים התמונות מתאימות. הסקילים קוראים את המקורות הפעילים מהאתר דרך `scripts/creator_agent.py sources`, בוחרים תמונות שמתאימות לנושא ולקהל היעד, ושומרים את פרטי המקור בפרויקט. אפשר גם להעתיק בקשת יצירה מכרטיס אלבום באתר. חיבור אישי לאתר נדרש גם לטעינת המקורות; התמונות נבחרות ומיובאות מקומית. עדכנו ערכות קיימות בעזרת `$davinci-update` כדי לקבל את היכולת.

בלשונית **מקורות → רקעים לתוכן** אפשר להעלות רקעים עם שם ותיאור, ובמידת הצורך תמונה נפרדת לשקף הפתיחה. לפני יצירת מצגת או סרטון חדשים הסוכן חייב לבחור רקע פעיל בהתאם לקונטקסט, או לפי שיקול דעתו החזותי כשאין התאמה ברורה. הבחירה והסיבה נשמרות בפרויקט יחד עם התמונות. רקע אתגר החללית כבר כלול. ראו `docs/backgrounds.md`.

הערכה כוללת סקילים ליצירה, ייבוא, פרסום ועדכון, את כלי היצירה, המיתוג והגופנים. אין צורך בגישה ל־Git, בהתקנת cloudflared או במפתחות Cloudflare. נדרשים חיבור לאינטרנט והרשאה להתקנת הכלים; הסוכן יתקין Python 3.10 ומעלה אם הוא חסר ויכין סביבה מקומית. אם מערכת ההפעלה דורשת אישור להתקנה, הסוכן יציג את הפעולה הנדרשת. החיבור לאתר משתמש בהתחברות האישית שלכם למערכת הלמידה ובאישור הסוכן בדפדפן. האישור נשמר במחשב ל־30 יום; אפשר לבטל אותו דרך ״החשבון שלי״ באדמין, או להריץ `scripts/creator_agent.py disconnect` כדי לנתק את המחשב. שירותי AI והפקת קריינות משתמשים בחשבון ובאישורים שלכם בנפרד.

מקורות התוכן נשארים ב־`projects/`, ותוצרים ב־`outputs/` או בתיקיית `output/` של הפרויקט. פרסום שומר גם גיבוי פרטי של המקורות. אפשר להוריד גם מקורות ישנים שנשמרו באתר. אם מישהו פרסם בינתיים גרסה חדשה, הסוכן יעצור ויבקש לשלב אותה עם העריכות המקומיות. קבצים שפורסמו מיועדים לצפייה באתר; בחירת ספרייה אינה הרשאת צפייה פרטית.
