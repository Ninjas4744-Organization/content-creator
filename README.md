# Da Vinci · Presentations Creator

מצגות וסרטוני הסבר בעברית, במיתוג Da Vinci 4744. פותחים את תיקיית הריפו בעוזר עם גישה לקבצים ומבקשים ליצור. הסקילים, הרקעים, הלוגואים, הגופנים, הדוגמאות וכלי הייצוא נמצאים כאן.

![דוגמת המיתוג](examples/community/poster.jpg)

## מתחילים בשיחה

אחרי clone, פתחו את **תיקיית השורש** של הריפו כפרויקט מקומי ב־ChatGPT/Codex או Claude Code. כתבו למשל:

> צור לי מצגת של 10 שקפים על גיוס ספונסרים לקבוצת FIRST. הקהל הוא צוות חדש, משך ההדרכה 20 דקות. השתמש בסקיל המצגות ובמיתוג שבריפו, והפק PowerPoint ותצוגה בדפדפן.

או:

> צור סרטון הסבר אינטראקטיבי בעברית על הפעילות הקהילתית שלנו, באורך כשתי דקות, עם קריין וקריינית דרך Gemini, מוזיקה, אנימציות ושתי שאלות לצופה. השתמש בסקיל הסרטון שבריפו.

להתרשמות מיידית, בלי התקנה: [מצגת בדפדפן](examples/community/presentation.html), [PowerPoint לדוגמה](examples/community/presentation.pptx), [סרטון עם פרקים ושאלות](examples/community/interactive/index.html). הנגן המצורף מפנה לסרטון שנמצא לידו בריפו; העתיקו את תיקיית הדוגמה כולה כשמשתפים אותה.

העוזר קורא את `AGENTS.md` ואת הסקיל המתאים. ב־Claude Code אפשר גם להקליד `/davinci-presentation` או `/davinci-interactive-video`. הוראות מדויקות ומגבלות לפי יישום נמצאות ב־[מדריך היישומים](docs/apps.md). בחלון צ׳אט שאין לו גישה לתיקייה מקומית צריך להעלות את הקבצים או לעבוד בסביבת קוד; clone במחשב לבדו אינו נותן לצ׳אט גישה אליהם.

## הפעלה ראשונה

דרוש Python 3.10 ומעלה. התקנת התלויות דורשת אינטרנט בפעם הראשונה. הכלים עובדים ב־macOS, Linux ו־Windows; הבדיקות בפועל בריפו הזה בוצעו ב־macOS.

```sh
python3 scripts/setup.py
```

ב־Windows הריצו `py scripts/setup.py`. אין צורך לשנות הגדרות כלליות של העוזר. אחרי ההתקנה משתמשים ב־`.venv/bin/python`; ב־Windows החליפו אותו ב־`.venv\Scripts\python.exe`.

נסו את דוגמת המצגת, בלי חשבון חיצוני ובלי מפתח:

```sh
.venv/bin/python -m davinci_creator deck examples/community/content.json --out outputs/community-deck
```

פתחו `outputs/community-deck/presentation.html`, או את `presentation.pptx` לעריכה. למצגת PowerPoint במחשב אחר כדאי להתקין את גופני Rubik המצורפים. [פקודות נוספות](docs/commands.md) כוללות יצירת פרויקט חדש, רינדור סרטון ובדיקות.

## מה כלול

- **שני סקילים** ליצירת מצגת וליצירת סרטון אינטראקטיבי. עותקים מקומיים ל־Codex ול־Claude Code.
- **מיתוג מלא**: רקעים, סמל, שם, מספר קבוצה, wordmark, שני משקלי Rubik ורישיון הגופן, תמונות קבוצה ורובוט וקובץ הייחוס.
- **מצגות**: PowerPoint עם טקסט ניתן לעריכה, HTML עצמאי להצגה בדפדפן, הערות מנחה ותמונות לבדיקת העיצוב.
- **סרטונים**: Python, מעברים והנפשות, מוזיקה ואפקטים מקוריים שנוצרים בקוד, איזון מוזיקה מול דיבור, קריינות Gemini בקולות Kore ו־Puck וכתוביות בעברית.
- **נגן אינטראקטיבי**: פרקים, חיפוש בתמלול, מהירות צפייה, שמירת התקדמות מקומית ושאלות עם משוב. ה־MP4 הוא גרסת צפייה רציפה; האינטראקטיביות נמצאת בנגן HTML.
- **דוגמה מוכנה**: מבוא לקהילה בפירסט, הסרטון שאושר והקריינות השמורה שלו. אפשר להריץ את הדוגמה בלי לשלוח בקשה ל־Gemini.

## קריינות חדשה

רק יצירת קריינות חדשה דורשת מפתח Gemini וזמינות של מודל TTS בחשבון. הגדירו `GEMINI_API_KEY` בסביבה, או העבירו `--key-file` עם נתיב לקובץ פרטי. אין להדביק מפתחות בצ׳אט או לשמור אותם בריפו. `.env.example` מתעד את השמות בלבד; הכלי אינו טוען `.env` אוטומטית.

```sh
.venv/bin/python -m davinci_creator tts projects/my-training/content.json
.venv/bin/python -m davinci_creator video projects/my-training/content.json --out projects/my-training/output/video
```

הדיבור נשמר במטמון לפי התוכן, הקול, המודל וסגנון ההגשה. שינוי שלהם מחייב קריינות חדשה. [תיעוד Gemini הרשמי](https://ai.google.dev/gemini-api/docs/speech-generation) מסביר את מנוע הקריינות והמודלים.

## עריכה ושיתוף

כל פרויקט מקבל `brief.md` ו־`content.json` ב־`projects/`. אפשר לשנות את הקובץ דרך העוזר או ידנית ולייצא מחדש. [פורמט התוכן](docs/content-format.md) ו־[מדריך המיתוג](docs/brand.md) מסבירים את הבחירות.

לשיתוף נגן יש להעביר את כל תיקיית `interactive/` יחד. אפשר לפתוח `index.html`; אם הדפדפן מגביל כתוביות או קבצים מקומיים, הפעילו את פקודת `serve` שבמדריך. אין בנגן שירות חיצוני או שליחת נתוני צפייה.

הריפו נוצר מקומית. אחרי שתיצרו remote ותדחפו אליו, אפשר יהיה לשתף את כתובת ה־clone. קובצי פלט, סביבות התקנה ומפתחות אינם נכללים ב־Git. [מקורות וזכויות הנכסים](assets/README.md) נשמרים לצד הקבצים.
